StockQ — 即時股票追蹤看板

Rust + ratatui 打造的終端機股票追蹤器，支援台股與美股即時報價。

台股 · 美股 · 終端機程式
前往 GitHub Repo 下載 main.zip

功能

即時更新報價

更新間隔可自訂，預設 10 秒。

紅綠燈漲跌視覺化

漲跌一目了然。

設定選單

調整更新頻率、新增 / 刪除追蹤股票。

雙資料源自動切換

CMoney + Yahoo Finance，來源失效時自動切換。

兩個追蹤器

台股

taiwan_stock/stock_tracker.exe
設定在 taiwan_stock/config.json

主要來源 CMoney，備用 TWSE MIS。

美股

us_stock/us_stock_tracker.exe
設定在 us_stock/config.json

主要來源 CMoney US，備用 Yahoo Finance。

使用方式

  1. 下載 zip 或 clone 這個 repo：git clone https://github.com/kimble11/StockQ.git
  2. 雙擊 stock_launcher.bat 開啟啟動選單
  3. 按 1 台股、2 美股

從原始碼編譯需要安裝 Rust：台股在 taiwan_stock/stock_tracker_ui、美股在 us_stock/us_stock_tracker_ui 執行 cargo build --release。

操作方式

按鍵功能
↑ ↓選取股票
S進入設定
Q離開
A新增股票
D刪除股票
ESC返回

設定檔

修改 config.json 自訂追蹤清單與更新頻率：

{
  "interval": 10,
  "watchlist": [
    { "id": "2330", "name": "台積電" },
    { "id": "TSLA", "name": "特斯拉" }
  ]
}

interval：更新秒數（1–300）。台股輸入股票代號（如 2330），美股輸入 ticker（如 TSLA）。

技術棧

語言 Rust · UI ratatui + crossterm · 非同步 tokio · HTTP reqwest · 序列化 serde + serde_json · License MIT
